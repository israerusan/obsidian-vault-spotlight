PAYMENT PLATFORM OPTIONS (instead of Gumroad)
==============================================

Your plugin uses offline license keys — any platform works as long as you
deliver the key after purchase. Change the purchase URL in
Settings → Vault Spotlight → Purchase page URL.

RECOMMENDED ALTERNATIVES
------------------------

1. LEMON SQUEEZY (best overall Gumroad replacement)
   https://www.lemonsqueezy.com
   • Handles tax/VAT globally (merchant of record)
   • Built-in license keys + API
   • Clean checkout, good for software
   • ~5% + payment fees
   • Use "License keys" product type, deliver key in receipt email
   • Run: npm run license:generate -- {buyer_email}  (same as now)

2. PAYHIP (simplest to run day-to-day)
   https://payhip.com
   • Very easy product setup
   • Digital downloads + optional license field in order emails
   • Lower learning curve than Gumroad
   • You manually paste generated keys into delivery template
   • ~5% fee on free plan

3. STRIPE PAYMENT LINK + EMAIL (most control, more work)
   https://stripe.com
   • $0.30 + 2.9% per sale
   • Use a one-page site (Carrd, Notion, GitHub Pages) + Stripe Payment Link
   • On webhook/payment success, run license:generate and email buyer
   • Best if you want zero platform lock-in

4. POLAR.SH (indie-friendly, open source vibe)
   https://polar.sh
   • Good for digital products + subscriptions
   • Newer, growing fast in dev tools space
   • Can sell one-time products

5. KO-FI SHOP (ultra simple, limited)
   https://ko-fi.com
   • Easy shop setup
   • Fine for low volume; less professional for license delivery
   • Put license key in digital file or manual follow-up

6. KEEP GUMROAD BUT SIMPLIFY
   • Only use Gumroad for checkout — ignore their app/features you don't need
   • Product URL stays the same in the plugin
   • Generate keys locally with: npm run license:generate -- email
   • Paste into Gumroad "content" file per order (or use Zapier)

WHAT STAYS THE SAME
-------------------
• Plugin license verification (offline, no server)
• npm run license:generate -- buyer@email.com
• scripts/customer-license-template.txt for delivery email

SUGGESTED MOVE
--------------
If Gumroad feels restrictive → try Lemon Squeezy first.
Setup time: ~30 minutes. Better license key tooling than Gumroad.
